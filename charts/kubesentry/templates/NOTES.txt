{{- if .Values.agent.enabled }}

4. Node agent
   DaemonSet {{ $fullname }}-agent in namespace {{ $agentNS }} reports to {{ include "kubesentry.ingestURL" . }}{{ if .Values.agent.fanout }} and fans out to every replica{{ end }}.
   It needs hostPID, which only the Pod Security "privileged" level allows:
     kubectl label namespace {{ $agentNS }} pod-security.kubernetes.io/enforce=privileged --overwrite
{{- if ne $agentNS $ns }}
   The server's namespace can then enforce "restricted":
     kubectl label namespace {{ $ns }} pod-security.kubernetes.io/enforce=restricted --overwrite
{{- else }}
   It shares the server's namespace, so that namespace cannot enforce "restricted".
   Set agent.namespace to a separate namespace to split them.
{{- end }}
{{- end }}
